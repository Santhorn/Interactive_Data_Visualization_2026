# Prompts ที่ใช้ช่วยพัฒนางาน

1. ช่วยตรวจสอบข้อมูล CSV และสรุปปัญหา Data Quality ที่พบ พร้อมเสนอแนวทาง Data Cleaning ที่อธิบายได้
2. ช่วยสร้าง Interactive Data Visualization ด้วย HTML/CSS/JavaScript โดยใช้ D3.js และ Chart.js จาก cleaned CSV
3. ช่วยเพิ่ม filter, tooltip, responsive layout และกราฟอย่างน้อย 4 รูปแบบตามโจทย์รายวิชา
4. ช่วยตรวจสอบข้อมูลจังหวัด เดือน อายุ เพศ และยานพาหนะให้ใช้ค่าจาก Dataset จริง ไม่สร้างข้อมูลขึ้นเอง
5. ช่วยแก้ปัญหา JavaScript ที่ทำให้ filter ไม่ทำงาน และปรับหน้า Dashboard ให้เรียบง่ายเหมาะกับการนำเสนอ
6. ช่วยจัดโครงสร้าง Repository, README และ Process Report ให้ตรงตามหัวข้อสอบ Interactive Data Visualization Project
